# Herramientas PDF

Suite profesional y gratuita de herramientas para documentos PDF con procesamiento 100% en el navegador del usuario (Client-Side).

## 🚀 Características y Herramientas

1. **Unir PDF**: Combina dos o más archivos PDF en un único documento, permitiendo reordenar los archivos antes de fusionarlos.
2. **Dividir PDF**: Extrae rangos específicos de páginas (ej. `1-3, 5, 8`) o separa todas las páginas de un PDF en archivos independientes empaquetados en un archivo `.ZIP`.
3. **Comprimir PDF**: Optimiza y reduce el peso de tus documentos con niveles seleccionables (Recomendada, Alta o Baja compresión) mostrando el porcentaje de ahorro de espacio.
4. **Girar PDF**: Rota todas las páginas a la vez (+90°, 180°) o rota páginas individuales con cuadrícula interactiva de miniaturas.
5. **JPG a PDF**: Convierte imágenes JPG, PNG o WebP a PDF con opciones de formato A4 vertical, horizontal o ajustado al tamaño original de la imagen, con márgenes configurables.
6. **PDF a JPG**: Convierte cada página de un archivo PDF a imagen JPG en alta resolución con descarga individual o en paquete `.ZIP`.
7. **Eliminar páginas de PDF**: Selección visual e interactiva de páginas innecesarias para removerlas del documento final.
8. **Extraer páginas de PDF**: Selección visual de páginas clave para generar un nuevo PDF únicamente con las páginas deseadas.
9. **Ordenar páginas de PDF**: Reorganización interactiva del orden de las páginas de un documento con botones de desplazamiento.
10. **Añadir páginas a PDF**: Inserta páginas de otro documento PDF o imágenes al inicio, al final o después de una página específica.

## 🔒 Privacidad y Rendimiento

- **100% Local**: Todo el procesamiento se realiza en la memoria del navegador usando `pdf-lib`, Mozilla `pdf.js` y `jszip`.
- **Sin subidas a servidores**: Tus documentos privados nunca salen de tu dispositivo ni viajan a través de la red.
- **Sin registros ni pagos**: No requiere registro, suscripciones ni tarjetas de crédito.
- **Diseño Responsive & Modo Oscuro**: Experiencia optimizada tanto para smartphones como para computadoras de escritorio.
- **Preparado para AdSense**: Contenedores estandarizados no intrusivos listos para incorporar bloques publicitarios sin alterar la experiencia del usuario.

## 💻 Desarrollo local

```bash
npm install
npm run dev
```

La aplicación estará disponible en `http://localhost:3000`.
